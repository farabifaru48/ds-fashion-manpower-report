# DS Fashion Ltd - Daily Manpower Report

A personal report-making tool built for DS Fashion Ltd, a garments factory.
It is used by IE Planning to prepare the daily "Today Manpower Present Status"
report digitally instead of on paper.

## Features
- Line-wise R/M, OP/HP, HP entry with auto totals
- Others section (Size set, Alter, Piping, AESN, Heat seal, Extra)
- Quick sum input (e.g. 12+12)
- Grand total: OP, HP and overall total
- Export report as PNG image
- Share directly to a WhatsApp group
- Works on mobile, no install needed

## How to use
1. Open the link on your phone or PC.
2. Select the date and fill in the numbers.
3. Tap "WhatsApp / Share" or "PNG Download".
4. Tap "Notun din" to start a fresh report next day.
